
ASCENDRA LEARNING
Singapore Premium Multi-Disciplinary Education Platform

PROJECT VISION
Ascendra Learning is a premium lifelong learning ecosystem for Singapore covering Academic, Technology, Business, Languages, Creative Arts, and Professional Development.

CORE UX PRINCIPLES
- Sheryians-inspired philosophy (not a clone)
- Storytelling-driven layout
- Large typography
- Scroll-based interactions
- Strong visual hierarchy
- Generous whitespace
- Dynamic content from JSON

NAVIGATION
